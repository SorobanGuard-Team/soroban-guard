What it does

Everything a Soroban developer needs

From first build to production deploy — SorobanGuard covers the gaps that stellar-cli doesn't.

🔍
Validation Pipeline
9 automated checks covering toolchain, WASM correctness, Soroban interface compliance, export inventory, and secret scanning.
🧬
WASM Inspection
Deep binary analysis using wasmparser — exports, imports, custom sections, contractspecv0 ABI, size breakdown, and SHA-256 fingerprint.
🧪
Test Utilities
sorobanguard-test-utils crate: LedgerHelper, EventAssert, snapshot_test! macro — reduces contract test boilerplate to a minimum.
📄
Multi-format Reports
Every check run produces JSON (machine-readable), Markdown (PR-friendly), and colour terminal output — all in one pass.
⚙️
GitHub Actions CI
Drop-in workflow with lint, host tests, contract tests, and sorobanguard-check jobs. Works on ubuntu, windows, and macos runners.
📐
Starter Templates
Counter, fungible token, and two-party escrow contracts — all production-patterned, fully tested, and ready to fork.
Validation

9 checks out of the box

Every check has a unique ID, a fix hint, and runs in under a second (except the build step).

01
toolchain
Rust version ≥ 1.84 and stellar-cli ≥ 30
02
wasm_target
wasm32v1-none target installed via rustup
03
contract_build
stellar contract build exits 0
04
wasm_exists
Output .wasm file is present on disk
05
wasm_size
Binary ≤ configured limit (default 256 KiB)
06
wasm_valid
File parses as valid WebAssembly
07
soroban_interface
soroban_env_common imports present
08
contract_exports
At least one public function exported
09
no_credentials
No secret key patterns in source tree
Installation

Up in three commands

Requires Rust 1.84+. No wallet, no testnet, no credentials needed for the default checks.

# Install prerequisites rustup update stable rustup target add wasm32v1-none cargo install stellar-cli --features opt --locked # Clone and install SorobanGuard git clone https://github.com/your-org/sorobanguard cargo install --path sorobanguard/crates/cli --locked # Run your first check cd my-contract sorobanguard check
# .github/workflows/ci.yml jobs: sorobanguard: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: dtolnay/rust-toolchain@1.84.0 with: targets: wasm32v1-none - run: cargo install stellar-cli --features opt --locked - run: cargo install --path crates/cli --locked - run: sorobanguard check --report-dir reports/ - uses: actions/upload-artifact@v4 with: name: sorobanguard-reports path: reports/
# sorobanguard.toml (place in contract root) [validation] strict_size = false max_wasm_size = 262144 # 256 KiB [reporting] report_dir = "sorobanguard-reports" json_report = true md_report = true [toolchain] require_stellar_cli = true min_rust_version = "1.84.0"
